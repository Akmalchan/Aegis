          Who does what.

          Guild.ai

          Hosts 11 agents, wakes them on every push, limits each to its own repos.

          Semgrep

          Finds the bug, checks every fix and every handoff between agents.

          OpenAI

          Writes the fix for the flagged lines only.

          ClickHouse

          Remembers every finding across the fleet and decides what to fix first.

          GitHub

          Statuses, Issues, PRs, merges.

          Why you can trust it.

          • The model never decides the verdict. Semgrep does.
          • A fix ships only if a test fails before and passes after.
          • Agents don't trust each other: everything they hand over is scanned.

          Everything AEGIS does.

          One column per prize track

          For Guild

          hosting agents11 agents · 23 triggers
          • 11 hosted agents on Guild, woken by GitHub webhooks
          • 3 sentinels × 3 repos each owns its own repos
          • Sub-agents as tools triage, remediator, verifier
          • Warden on cron full re-scan every 30 min
          • Reporter, hourly fleet report with charts
          • Rulesmith and onboarder new rules and repos from an Issue
          • Least-privilege credentials real denies by the proxy
          • Scanner as integration custom Guild tool, plus evals

          For Semgrep

          findings in AI-written code22 rules · 0 ERROR self-audit
          • Diff-only scans --baseline-commit, only what changed
          • 22 custom rules many with a ready autofix
          • Rules for agent code LLM output → shell, MCP args → shell, secrets in prompts
          • Injection in comments orders to a reviewer are a finding
          • Dataflow traces source → sink quoted in the Issue
          • SARIF export findings in the GitHub Security tab
          • nosemgrep audit no reason given = a finding
          • Hooks on every edit Semgrep checks what Claude Code writes

          For ClickHouse

          real-time analytics~39k findings · timeline ~45 ms
          • Every event stored scans, findings, actions
          • History backfill 38,739 findings, 2,007 commits
          • Seen-before suppression known and dismissed don't re-alarm
          • Priority score picks what to fix first
          • Rule precision noisy rules demoted automatically
          • Real-time rollups materialized views on every insert
          • Live dashboard this page reads from it

          For Pi

          agentic product security, end to endpush → merge 2 min 34 s
          • Nobody clicks push to merged PR by agents
          • Triage first traces source, sink, impact
          • Targeted test fails before, passes after
          • 3-layer verify re-scan, repo tests, targeted test
          • 0 findings ≠ clean parse errors fail the gate
          • Handoff guard agents scan what they pass on
          • Merge only verified otherwise nothing ships

          For OpenAI

          span-only fixesgpt-4.1
          • Span-only patch rewrites the flagged lines only
          • Only model step Semgrep decides the verdict
          • Patch guarded new findings reject the fix
          • Proven by test the fix must pass the targeted test
          • Two fix sources Semgrep autofix or OpenAI patch
