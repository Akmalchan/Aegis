                How it works

                One push.

                Five moves, zero clicks
                1. 01

                  Wake

                  Push fires a Guild trigger.

                2. 02

                  Judge

                  Semgrep diffs the push. Deterministic.

                3. 03

                  Act

                  Red status, Issue, fix PR.

                4. 04

                  Verify

                  Re-scan. Issue closes itself.

                5. 05

                  Remember

                  ClickHouse. Dismissed once, never again.

                Run it yourself.

                Same engine and rules as the fleet. Your laptop, your CI. No server, no account.
                Open source CLI
                pipx install git+https://github.com/Akmalchan/Aegis
                • aegis scanScan this repo. Exit 1 if unsafe, so CI fails the build.
                • aegis scan --diff mainOnly what this branch introduced, like a push.
                • aegis scan owner/repo --sarif out.sarifAny GitHub repo, plus SARIF for the Security tab.
                • aegis fleetFleet numbers and the exposure clock.
                • aegis watchLive feed of the agents, in your terminal.
