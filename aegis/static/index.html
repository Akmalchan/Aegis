        Architecture

        How Aegis
        thinks.

        The detection has no context window and no opinion: Semgrep's verdict is deterministic. The agents only do what a security engineer would do next, and every action is fenced, recorded and verified.

        1. 01

          Wake

          A push to any guarded repo fires a Guild webhook trigger. The sentinel that owns that repo wakes up with the raw GitHub payload.

        2. 02

          Judge

          The sentinel asks the scanner one question: did this change make the repo unsafe? Semgrep runs against the previous commit, so only what the push introduced counts.

        3. 03

          Act

          Unsafe: a red commit status, one Issue per finding with impact and fix, and a pull request with the patch. Safe: green, and the PR gets approved.

        4. 04

          Verify

          When the fix lands, the sentinel scans again. The finding is gone, so the Issue closes itself with the commit that proved it.

        5. 05

          Remember

          Every scan, finding and action lands in ClickHouse. A false positive dismissed once is never filed again anywhere in the fleet.

        Deterministic

        No model decides what is vulnerable.

        The verdict is Semgrep's. The LLM explains and patches; it never gets to say "looks fine". A comment telling the agent to approve the file is flagged as an attack.

        Fenced

        A hundred agents with write access is a threat.

        Each sentinel can only touch its own three repos. Guild's credential proxy enforces that, not a prompt.

        Remembered

        The fleet learns.

        22,000+ findings across the full history of real repos. Rising repos, noisy rules and reopened bugs change what agents do tomorrow.

        Built on

        Guild.ai

        Hosts the agents: webhook and cron triggers, the scanner as a custom integration, credential policies, skills, sub-agents, evals.

        Semgrep

        Detection: baseline-diff scans, bundled rules with autofixes, registry packs, prompt-injection rules for code that talks to agents.

        ClickHouse

        Fleet memory: enrichment on every scan, insights for the warden, the full-history posture timeline in milliseconds.

        GitHub

        Where the agents act: commit statuses, Issues, branches, pull requests, reviews.
