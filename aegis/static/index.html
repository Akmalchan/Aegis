        How it works

        Every push is checked, fixed and proven — by agents, not people.

        The loop.

        One push, 8 steps, nobody clicks
        1. 1

          Push

          GitHub wakes the agent on Guild.

        2. 2

          Semgrep finds

          Only what this push changed.

        3. 3

          Proven real

          A test that fails on the bad code.

        4. 4

          OpenAI fixes

          Rewrites only the flagged lines.

          Only step a model writes
        5. 5

          Re-checked

          Re-scan, repo tests, and the test passes.

        6. 6

          One Issue

          The whole story in one place.

        7. 7

          Decision

          Verified: agent merges. Not: nothing ships.

        8. 8

          Green

          The merge is scanned again.

        Who does what.

        Guild.ai

        Hosts 11 agents, wakes them on every push, limits each to its own repos.

        Semgrep

        Finds the bug, checks every fix and every handoff between agents.

        OpenAI

        Writes the fix for the flagged lines only.

        ClickHouse

        Remembers every finding across the fleet and decides what to fix first.

        GitHub

        Statuses, Issues, PRs, merges.

        Why you can trust it.

        • The model never decides the verdict. Semgrep does.
        • A fix ships only if a test fails before and passes after.
        • Agents don't trust each other: everything they hand over is scanned.

        Run it yourself.

        Same engine and rules as the fleet. Your laptop, your CI. No server, no account.
        Open source CLI
        pipx install git+https://github.com/Akmalchan/Aegis

        • aegis scan owner/repo --sarif out.sarifAny GitHub repo, plus SARIF for the Security tab.
        • aegis fleetFleet numbers and the exposure clock.
        • aegis watchLive feed of the agents, in your terminal.
